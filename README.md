# Tutedude MERN Stack – Task 9

## About
A responsive Laundry Services landing page with a CSS-only hamburger menu for mobile screens.

## Features
- Hamburger icon visible only on mobile screens
- Mobile navigation menu opens when the hamburger button receives focus
- Desktop navigation remains visible on larger screens
- Responsive laundry services hero section
- Flexbox and CSS media queries
- No JavaScript or Bootstrap used
- When we hover on button it show some animation type

## Technologies
- HTML5
- CSS3

## How to Run
1. Extract the ZIP file.
2. Open `index.html` in a web browser.
3. Use a mobile-sized browser window and click the hamburger icon to show the menu.

## Files
- `index.html` — webpage structure
- `style.css` — styles and responsive menu
- `README.md` — project information
